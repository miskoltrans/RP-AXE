# Changelog

The in-game copy (shown once per new version by KerbalChangelog) is
`GameData/RP-AXE/RP-AXE-Changelog.cfg`; keep the two in step.

## 0.9.3 — tree cleanup, Sol textures, dev bridge removed

- **No more localhost bridge in AXE.dll.** Up to 0.9.2 the plugin carried a dev-only query bridge (a
  listener on 127.0.0.1, off unless switched on by config, flag or environment variable). It is a
  developer tool, so it now lives outside the mod entirely, and the release script refuses an
  `AXE.dll` that contains it. Nothing changes for players.
- **Presets: texture size is your choice.** The Sol preset offers Sol's recommended sizes ticked per
  system (16K Earth and Mars, 8K Mercury, Venus, Jupiter and Saturn, 4K the rest; about 6 GB) and asks
  for any system you untick. The RSS presets offer their one texture pack ticked (4K on RSS-Low, 16K
  on RSS-High) and ask for another size if you untick it. The preset assets were re-uploaded to the
  0.9.3 release with this on 2026-10-24; the first 0.9.3 upload fixed the sizes.
- **README: the RSS command-line install names `KSPBurst`.** Headless CKAN skipped it (2026-10-24,
  on the published 0.9.3 files too), leaving FAR and RealAntennas unable to load.
- **Sol docs:** volumetric clouds (Blackrack's V5), the lunar impactor contract that may not complete
  on Sol 0.9.5, and the much tighter Mimas flyby.
- **The Mission Control "RP-1" folder is now called "Contracts".**
- **Parking and Experimental are gone from the tech tree.** Both were developer holding pens. Parts the
  tree does not place can no longer be researched at all, and the Travers SAR is removed: a first-tier
  scanner that outclassed the whole tier-9 radar node.
- **Upper-Atmosphere Sounding's description no longer suggests it unlocks the thermometer and
  barometer.** You start with both; the node unlocks no hardware and leads to the mass spectrometer and
  magnetometer.
- **README warns that this is a hard career** and a bad run of tree picks can leave you
  without a way to earn the science to recover.

## 0.9.2 — avionics strength restored

- **Avionics overload is back to 0.9.0 strength.** 0.9.1's Harmony fix halved the overload penalty,
  but every value had been tuned, and the career played, with the corruption running twice per tick.
  The second pass is now restored on purpose (`CorruptionPasses = 2`): misdirection up to 180°
  off-axis (the controls reverse from about 6% over), twice the noise, overgain squared. The PAW's
  off-axis figure shows the real bound. RCS translation is doubled the same way, without 0.9.0's leak
  from one thruster to the next.
- **Over-capacity avionics rows are red in the PAW.** Every row that means "this vessel lacks
  capacity" uses one alarm colour, and Capacity quotes the vessel mass next to the rating. The rows ask
  the same test that corrupts the controls: a seated crewed pod reads "crewed pod has control", a unit
  over its own rating while a larger unit steers says so, and launch clamps no longer count toward VAB
  mass.
- **Express presets renamed** so the planet pack is in the name: `RP-AXE-Express-High` / `-Low` are
  now `RP-AXE-Express-RSS-High` / `RP-AXE-Express-RSS-Low`, next to `RP-AXE-Express-Sol`. Same
  contents.

## 0.9.1 — Sol support, Harmony fixes

- **Fixed: AXE's Harmony patches on current CKAN installs.** RealFuels 15.16 changed the engine-config
  window, the engine-config purchase gate failed to patch, and Harmony skipped every AXE patch after
  it. Patches now apply one by one, and the gate supports both RealFuels versions.
- **Fixed: every AXE Harmony patch was applied twice.** The avionics overload corruption ran twice per
  physics tick, so 0.9.0's penalty was roughly double the design: misdirection up to twice the angle,
  twice the noise, overgain squared. RCS translation corruption also leaked past the thrusters. Over
  capacity, a craft now flies at the designed strength, which is noticeably gentler. Also fixed:
  engine-upgrade tooltip stats shown twice, and the bimodal-toggle message posted twice.
- **Sol support:** `GameData/RP-AXE/design/Sol/` (generated by `tools/gen_sol_compat.py`) keeps a Sol
  career on the RSS balance: per-body science, Earth sub-40 km removal, gas-giant heat, SCANsat
  altitudes, ground-station antennas, outer-planet resources. New `RP-AXE-Express-Sol.ckan` preset;
  the RSS texture choice in `RP-AXE.netkan` accepts Sol-Core. Guide: `docs/SOL.md`.

## 0.9.0 — public beta (first release)

- **Tech tree:** a from-scratch, discipline-based tree of ~530 breakthrough nodes compiled from
  `tree/nodes.yaml`, science-gated, with an in-game R&D render (discipline colours, hover lineage,
  OR-gates drawn dashed).
- **Ported from RP-1:** the science instrument suite and crewed science, 35 programs and their
  contracts (running on AXE's own ContractConfigurator types), the engine-config upgrade ladders,
  the DSN tracking-station levels, airlaunch, range safety, non-reentry-rated parts, dev parts.
- **AXE's own:** avionics with steerable-mass capacity and control corruption on overload instead
  of a lock; an in-editor flight simulator; a funds economy with no build times, tooling,
  maintenance, crew training or reliability grind; free launch-site switching; a capstone +
  program-completion payout model.
- **KerbalismLab:** 65 crewed-station experiments integrated and rebalanced.
- **Packaging:** CKAN metadata (`RP-AXE.netkan`), KSP-AVC version file, `tools/package_release.py`.
