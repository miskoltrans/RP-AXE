# design/ — RP-AXE transformations & new content

Everything RP-AXE *does* to the vendored RP-1 seed, plus everything it adds, lives here as
ModuleManager patches and new config. Every patch applies **after** the seed and after RO /
RealFuels — `:FOR[RP-AXE]`, `:AFTER[...]` or `:FINAL`, never a bare pass. Never edit `../seed/`;
change behaviour here. (Conventions: `docs/WORKFLOW.md`. Roadmap and decisions: `docs/RESTART.md`.)

| path | what it does |
|---|---|
| `AxeExternalTechRemap.cfg` | re-homes the stock / CTT tech ids that third-party part mods hard-code onto AXE nodes |
| `AxeKerbalismTechRemap.cfg` | same for the tech gates inside Kerbalism's own configs |
| `AxeGasGiantEmissiveFix.cfg` | stops RSS gas giants cooking orbiters (KSP radiates at the 1000 atm datum) |
| `StripAxedRP1Modules.cfg` | `:FINAL` strip of the RP-1 part modules AXE does not ship a reader for (`ModuleTooling*`, `ModuleAvionics`, `ModuleTagList`, …) |
| `Contracts/` | fixups to the vendored RP-1 contracts (dedupe, moon groups, docking latch, first-EVA rules, science titles) + the funds layer (`AxeCapstoneFunds`), stock contracts off, Skopos maintenance contracts off |
| `Programs/` | the program switcher: a charter contract per RP-1 program (`ActivatePrograms`), program completion / objective payouts |
| `Parts/` | per-part behaviour tags: non-reentry-rated, range safety, fixed avionics, no-EVA, non-recharge, reentry pressurisation, cut parts, upstream part fixes, geochemistry instruments |
| `Science/` | Kerbalism `Configure` tech gates, hard-drive ladder, Earth sub-40 km science removal, `CrewScience/` (RP-1 crewed science, tech-remapped) and `KerbalismLab/` (crewed-station lab science). Has its own `_README.md` |
| `Settings/` | what RP-1 used to own through its plugin: CustomBarnKit facilities + tracking-station ladder, `GAMEPARAMETERS`, strategy rescale, `HardRemoveNonRO`, RO career enable, KSPCommunityFixes, simulation, crew autopilot / physics |
| `Tree/` | the tech tree. **Generated by `tools/build_tree.py` from `tree/nodes.yaml` — do not hand-edit:** `AxeTechTree`, `AxeTreeMeta`, `AxePartPlacement`, `AxePartCost`, `AxePartFlyCost`, `AxeProcCostScale`, `AxeEngineConfigGates`, `AxeEntryCostMods`, `AxeEngineTechLevels`, `AxeGrantUpgrades`, `AxeFacilityGates`. Hand-authored: `AxeAvionicsCore` (the avionics ladder), `AxeAirlaunch`, `AxeAutostrut`, `AxeMliLadder`, `AxeOrphanedTech`, `AxePartOrigin`, `AxeProcParts` |
| `Filter_Extensions_Configs/` | editor part-category filter |
| `Sol/` | **generated by `tools/gen_sol_compat.py`**: `SolSystem`-gated twins of the body patches above plus RSS-side values Sol replaces (scanners, station antennas, outer-planet resources). Inert on RSS |

Node icons are the stock `RDicon_*` names resolved from the game's own atlas; nothing under
`Tree/` ships image assets.
